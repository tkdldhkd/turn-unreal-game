# 동굴 죽이기

카드를 배치하고 순서대로 발동시키는 2D 턴제 덱빌딩 게임입니다.

## 게임 소개

- 장르: 2D 턴제 덱빌딩
- 엔진: 언리얼 5.8.3

## 주요 특징

- 카드 드래그 앤 드롭
- 행동 순서 시스템
- 턴제 전투
- 캐릭터별 카드
- 덱 구성 시스템
- 진영 시스템
## 게임 방식

1. 카드를 뽑는다.
2. 행동 공간에 카드를 배치한다.
3. 턴을 종료한다.
4. 카드가 왼쪽부터 순서대로 발동한다.
5. 적과 전투를 진행한다.
6. 전투 보상으로 캐릭터를 강화한다.
7. 5주차 까지 생존하고 보스를 쓰러트리면 게임 클리어

## 조작법

마우스 클릭

## 개발 환경

- Unreal Engine 5.8.3
- Blueprint
- Windows

## 프로젝트 구조

- `BP_BattleField` : 전투 관리
- `BP_Player` : 플레이어 캐릭터
- `WBP_Card` : 카드 UI
- `WBP_Battle` : 전투 UI
- `Data Asset` : 카드 및 캐릭터 데이터

## 구현된 기능

- [o] 카드 드래그 앤 드롭
- [o] 카드 순서 정렬
- [o] 캐릭터 체력 시스템
- [ ] 덱 시스템 완성
- [o] 적 AI
- [ ] 스테이지 진행
